# strings

**a `/usr/bin` program** -- printable text in a file.

**Category:** Programming

## Synopsis

    strings [options] file...

## Description

Prints each run of four or more printable characters in a file -- the text a program carries.

It is GNU binutils 2.47, built for SaunaOS with the native compiler (`make native-toolchain`; `docs/cc-design.md`, stage 3), and takes every option binutils documents. An image built without that target has no `/usr/bin/strings`.
